# 导航与练习入口调整

2026-11-15。落实页面层级评审中的四项建议，保留 Reso UI V2.1 的角色、渐变、卡片、布局及现有练习方法。

## 行为

- 主导航为“Reso／聊过的事／我的”。Reso 固定进入当前账号的私人聊天：优先当前自己发起的事件，再使用其他自己发起的事件，没有时新建。受邀房间不会作为私人聊天入口，私人和房间草稿分别保留。
- “聊过的事”按事件查找，“重要的人”作为另一种查找方式。受邀事件标明“房间聊天”，人物事件入口说明消息对房间成员可见。
- “我的记录”汇总已保存故事、表达练习、开口练习和回访；“待回访”只显示尚未回看的回访。标记已回看后从待办中移除，原记录继续保留在“我的记录”和所属事件中。空待办可进入全部记录。AI 回访建议中的“查看已保存记录”返回所属事件记录。
- 练习入口及标题统一为“整理这件事／写下我的表达／练习怎么开口”。保留原有五幕、表达字段、排练字段、草稿和保存方式。

本次没有新增页面、依赖、后端接口或数据库迁移。独立 UI 参考预览保留原始设计。
