# 性能优化与验收

2026-11-14 的 Agent 真实回复链路优化见 [最新验收](performance-agent.md)。下文保留 2026-11-13 的数据库与构建基线。

2026-11-13。本轮优化三个实测路径：事件详情读取、历史消息翻页、正式应用的首屏 JavaScript。没有增加依赖或缓存私人业务数据，也没有修改 Agent 提示词、模型或上下文范围。

## 已实施

1. **补齐详情查询索引。** 0006 新增 followups(event_id,user_id,created_at DESC)、applications(event_id)、invites(event_id,created_at DESC)。基线采样中，这三组查询是主要数据库开销；回访表虽已有用户索引，仍需扫描该用户其他事件的记录。
2. **历史分页只取消息。** 新增 GET `/api/events/:id/messages?domain=private|room&before=<id>`，返回 messages 和 hasMore；沿用原授权、50 条上限、时间顺序及游标逻辑。前端“加载更早的消息”使用该接口，原详情接口继续兼容 before。游标限制在 PostgreSQL bigint 范围内，错误游标返回 400。
3. **演示代码按需加载。** Button、Bubble、Dialog、Card 原样移至共用 components.tsx，正式应用不再依赖演示 App；仅 `?preview=1` 动态加载演示代码。保留演示入口及加载失败提示，页面样式未调整。

## 测量方法

使用真实 PostgreSQL 随机隔离库和受限运行账号，本机真实 HTTP 请求。合成数据包含 30,000 条无关咨询申请、30,000 条无关邀请、同用户其他事件的 30,000 条回访；目标事件有 180 条私聊消息、60 条房间消息、30 条回访、3 条申请和 3 条邀请。没有调用模型或转写供应商。

独立进程轮次观察到主机负载波动，因此最终采用同一隔离库、同一 API 进程中的成对复测：先临时移除隔离库中的 0006 索引并使用完整详情翻页，再恢复索引并使用轻量翻页。每类请求先预热一次；记录样本中位数和样本 P95。接口耗时包括本机 HTTP、鉴权、业务查询与响应读取，不包括真实网络及模型生成。

计数器捕获业务连接池上的查询次数，不包含 Better Auth 通过独立 client 执行的查询。JSON 大小指响应正文 UTF-8 字节数，不含 HTTP 头或传输压缩。

## 成对复测结果

| 路径 | 请求数／并发 | 前 p50 / p95 | 后 p50 / p95 |
| --- | --- | ---: | ---: |
| 私聊详情 | 20 / 1 | 21.015 / 33.264 ms | 16.487 / 28.889 ms |
| 房间详情 | 12 / 1 | 16.408 / 23.168 ms | 15.196 / 22.014 ms |
| 私聊详情并发读取 | 24 / 4 | 24.799 / 47.155 ms | 19.408 / 24.331 ms |
| 历史消息页 | 16 / 1 | 25.161 / 43.889 ms | 5.310 / 8.883 ms |
| 私人 Agent 上下文组装，直接调用 | 12 / 1 | 5.694 / 9.980 ms | 5.480 / 6.946 ms |

历史消息页捕获的业务查询从 13 次降到 2 次，正文从 76,576 降到 33,941 字节；初始详情正文保持 76,614 字节。主要收益来自翻页不再重复加载回访、问卷、练习、邀请、申请和理解记录。上下文组装变化较小，本轮不据此宣称 Agent 效果或回复速度改善。

前后记录在 `.data/performance/paired.json`。此前单轮 before、indexed、lightweight 记录保留在同目录，用于说明负载波动，结论使用 paired 的成对数据。

## 构建体积

正常入口的最小化 JS（未 gzip） 从 333,117 降为 298,215 字节，减少约 10.5%；演示成为额外的 37,256 字节按需代码块。全部 JS 合计从 333,117 增至 335,471 字节。该优化减少正式用户首屏需要解析的代码，不减少所有页面总构建体积，不代表已测得 LCP、INP 或手机启动速度改善。

新增基准脚本已纳入项目 TypeScript 检查。`npm run benchmark:bundle` 检查构建的静态依赖图：演示模块必须仍然存在，并且不能出现在正式入口及其静态依赖中。体积记录在 `.data/performance/bundle-before.json` 和 `bundle-after.json`。
