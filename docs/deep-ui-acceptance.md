# 六项界面打磨与验收

2026-11-14。针对当前中文 Android 本机 MVP 执行 polish、bolder、quieter、distill、harden、onboard，保留 Reso UI V2.1 的角色、插画、配色和分享规则。没有新增依赖、数据库迁移或生产部署。

## 六项交付

| 项目 | 实际变化 |
| --- | --- |
| polish | 常用按钮、弹窗关闭、输入和练习步骤统一到至少 48px 触控尺寸；键盘焦点使用现有主蓝色；补齐按钮间距、忙碌状态和长文本换行。 |
| bolder | 发送消息使用已有蓝色强调样式；专业端接单和时间提议作为主操作，保留暂不接受等原有选择。主要按钮加重，仍使用原有三色渐变。 |
| quieter | 欢迎页保留一处隐私强调，其他承诺改为普通图文行；删除重复的安抚小标题；顶部返回和账户菜单去掉浮动圆底与阴影。 |
| distill | 写回访的表单下不再重复显示“还没有回访”的空列表；事件名称使用单行预览，完整内容保留在事件菜单和无障碍名称中。沿用聊天页隐藏底部导航的行为。 |
| harden | 事件读取失败有重新打开和返回列表，详情未读取时禁用输入；忙碌弹窗禁用关闭、保留表单并显示正在保存；登录失效清空密码并回到登录模式；从公开房间进入咨询申请时先读取私人详情。 |
| onboard | 欢迎页开始按钮置于滚动内容之外，窄屏大字体仍可直接使用；空私人对话提供一个可选工具入口，首条消息保存后收起；核对理解、成长和申请空状态提供实际下一步。 |

这里的 bolder 用于突出操作，quieter 用于收敛辅助装饰；没有更换品牌或增加宣传性效果。新增引导不要求完成问卷或教程才能聊天。

## 原生验收路径

设备为 Pixel9_API35／Android 15／ARM64（emulator-5554）。截图均来自 ADB；WebView 调试连接用于布置隔离测试身份、网络故障和读取布局数值，不能算作真机或人工用户研究。

| 路径 | 结果与证据（均在 `.data/deep-polish/`） |
| --- | --- |
| 注册到首次表达 | 实际注册后直接进入私人聊天；工具提示仅在空对话出现。`09-first-chat`、`14-first-chat-after`、`17-message-saved`。 |
| 读取失败 | 注入 GET 500，复现旧版停在加载状态；修复后显示恢复入口并禁用输入，可返回列表。`11-load-failure-before`、`12-load-failure-after`、`13-load-recovery-list`。 |
| 发送失败与离线 | POST 500 后保留草稿，重试只保存原消息一次；保持 WebView 离线连接时发送失败，文字仍在输入框且未写入数据库。`16-message-failed`、`17-message-saved`、`60-offline-draft-kept`、`final-state.json`。 |
| 练习草稿和保存 | 填写、离开、重新进入后内容保留；保存失败仍显示草稿；重试后实际落库并显示已保存。`32-nvc-restored`、`34-nvc-save-failed`、`45-nvc-saved`。 |
| 分享版本与撤回 | 受邀成员通过真实 API 接受；在 App 查看旧版本、核对并确认更新、撤回。接收方再次读取只得到获授权的固定版本，撤回后无摘要，私人聊天不进入房间。`50-shared-old-version`、`52-share-confirm`、`53-share-updated`、`54-share-withdrawn` 及 guest 检查 JSON。 |
| 房间与私人申请 | 在公开房间通过事件菜单进入申请，能看到真实的待处理测试申请，页面恢复私人可见范围。`55-owner-room`、`57-private-applications`。 |
| 登录与权限 | 普通密码错误保留邮箱和登录表单；会话失效退出受保护界面；受邀身份打开私人链接被拒绝，输入不可用。`62-login`、`65-login-error`、`92-guest-room`、`93-guest-private-denied`。 |
| 问卷和专业端 | 实际选择一项问卷答案，选中项有勾选标记且已保存；专业端完成接单，保留两个原有决策。`71-answer-selected`、`75-counselor-accepted`、`96-counselor-final`。 |
| 慢请求 | PATCH 延迟 10 秒时，关闭按钮及字段禁用；尝试关闭不丢编辑，完成后记录仍是刚才的内容。`89-dialog-busy`、`90-dialog-busy-retained`、`91-save-complete`。 |
| 字体、长文本、键盘 | 覆盖 412px 正常宽度、320px 与系统 200% 字体、中英文连续长标题和 emoji、夜间设置切换、横屏软键盘。无整页横向溢出；欢迎按钮和聊天输入仍可见，短屏保留事件与隐私范围。`83-welcome-200-final`、`85-landscape-keyboard`、`97-final-200-chat`、`98-final-200-tools` 和布局 JSON。 |

正文、辅助文本及主要按钮文字颜色按当前背景检查；主按钮三处渐变色上的对比度约 4.54–4.74:1，辅助文字约 4.80:1。不等同于完整可访问性认证。

## 数据保护与交付范围

写入验收使用单独创建的测试数据库和受限运行角色，模型和 ASR 凭据在验收进程中禁用。原有 WebView 会话与设备草稿先私下备份，完成后恢复；设备字体、屏幕尺寸、夜间和旋转设置恢复。原业务库排除正常会话元数据后，24 张表的全字段摘要比对结果见 `data-verification.json`；会话与存储恢复结果见 `session-verification.json`。临时数据库、角色和私有凭据副本在验收完成后清理。

APK 位于 `.data/android/Reso-local-debug.apk`，仍通过 ADB 转发加载本机 Vite/API，并非可脱离开发电脑使用的生产 App。

本轮未验收物理真机、TalkBack、多语言翻译、所有设备/输入法组合、真实模型与语音供应商、真实咨询运营或生产发布。引导的理解程度、使用率和沟通效果尚未进行真实用户研究，不把工程验收当作使用效果证明。
