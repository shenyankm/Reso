## 离线附件

本项目参考了《Reso 需求文档 V2.1》《Reso 技术核心、产品亮点与竞争壁垒分析》、队友资料包、21 张 UI 编号图、《Reso 20 小时青少年倾听录音：Agent 训练与路演价值》及《决策数据与 Agent 评测》等用户提供材料。Wang 决策框架和交互设计 V3.0 的可核验编号/元数据见 [离线编号目录](wang-source-catalog-v3.json)。

上述文件保持离线来源身份，不作为已授权、已专业审核或效果已经证实的凭据；完整聊天历史没有导出。资料文件名、版本和必要哈希用于设计追溯，不提供私人附件下载，也不公开微信账号标识或设备目录。
