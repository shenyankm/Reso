## 本轮修复

1. **Android 导出没有落盘。** 原先 Web Blob 下载在当前原生容器中没有保存处理。改为系统 CreateDocument，实际写入结束才报告成功。增加 Web 导出单元测试和原生取消、非法数据、保存后文件内容校验。
2. **刷新取消请求产生 500。** 异步鉴权期间连接关闭使限流器读取不到请求 IP。请求进入时保存 IP，保留原有限流与 IPv6 归一化。真实 HTTP 中断回归在修复前复现，修复后 30 次取消未再出现服务异常，后续请求正常。
3. **成功重试仍署名“系统”。** 消息 upsert 只更新内容和状态，遗留失败消息的作者名。统一随回复更新作者，同一消息 ID 从 error 恢复 complete 后署名为 Reso。数据库回归修复前失败、修复后通过，并加入 Android 重试断言。
4. **SSE 关闭后心跳未释放。** 实际业务断言完成、隔离库已删除后，Node 仍被 15 秒心跳定时器占用。关闭逻辑原来只依赖 socket 的 close 事件；改为服务关闭时主动清理订阅和心跳，响应 finish 或已关闭时也立即清理，并保持幂等。新增回归在修复前失败；未使用强制退出绕过资源泄漏。

未新增依赖，未修改 `.env` 中的供应商凭据，未对原用户历史消息做批量修正。

## 真实转写阻断

当前配置的 App ID／Access Token 握手被豆包返回 401，诊断标记为缺少资源授权；当前 2.0 小时资源和另行检查的旧版小时资源都被拒绝，未擅自改为旧版配置。资源及鉴权格式核对依据[官方流式语音识别文档](https://docs.volcengine.com/docs/doubao-voice/unidirectional-streaming-automatic-speech-recognition-websocket?lang=zh)。
