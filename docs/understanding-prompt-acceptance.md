# 重要理解核对入口

2026-11-15。保持 UI V2.1 的气泡、文字按钮、卡片及页面结构，将每条消息下的“核对这句话”收敛为“这符合你的意思吗？”。

只显示在 Agent 标记的重要总结或具体待核对推测旁；用户消息、普通聊天、旧的未标记消息、系统错误、安全提示及已有核对表单的建议卡不显示。点击后的原话来源、不同意、修改与确认流程保留，旧核对记录不删除。

类型标记保存在现有运行记录 JSON 中，消息详情与分页一致读取，严格按事件及私人／房间域隔离；没有新增依赖或数据库迁移。默认不重新分析历史消息。

验证进度：45 项单元测试、类型检查、生产构建及 5 项 Agent 集成测试通过。Android 14 个主流程及 Agent 专项通过（Node 含父测试 16 项）；证据在 `.data/e2e/2026-11-15T11-41-54-192Z/` 与 `.data/e2e-agent/2026-11-15T11-41-29-577Z/`，原会话已恢复，隔离数据库与角色已清理。前端、API 与 Worker 已统一发布为 `20261115T114721Z-ui-fixes`。服务器 25 项集成测试通过。

## 线上 AVD

不使用 ADB reverse，入口 JS／CSS 哈希与发布构建一致。通过真实模型完成五组检查：普通闲聊不显示入口；重要总结显示新文案；点击后不同意、修改和确认仍有效；具体推测可核对；表达建议卡保留自身表单而不重复显示消息核对按钮。

证据在 `.data/release-understanding/online-android/` 的 `results.json`、`01.png` 至 `05.png`、`restoration.json`、`cleanup.json`；`02.png` 展示重要总结下的新入口，`original-conversation-after-update.png` 展示原模拟会话不再逐条挂核对按钮。已清理一个临时账号、一个临时事件与对应队列任务，恢复原 Cookie 和设备存储，原体验账号及六轮模拟会话保留，AVD 停在该会话中。

没有重新构建原生 APK。未验证实体机、TalkBack 或真实语音；重要性由 Agent 标记，历史未标记消息不追溯分类。
