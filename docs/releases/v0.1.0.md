# Reso v0.1.0 开发预发布

首个公开源码版本，包含移动端 React/TypeScript 界面、Tauri Android 调试壳、Fastify API、独立 Agent Worker，以及数据库 V2.3 目标设计。此版本供开发和验收使用。

## 本版内容

- 私人聊天、SCQA、叙事/表达/排练、邀请与固定版本分享、人物与事件、专业支持和回访的已有实现。
- Agent 判断、动态路由、持续拒绝/安全状态、候选方法与用户确认后开始/保存的兼容层；新原生数据库契约尚未接入运行层。
- 76 张目标表、919 条字段条目、120 个复合关系、封闭 JSON 契约、五份替代 SQL 草案，以及独立审查九项修复。
- M1a/M1 的分批实施、旧数据回填、回滚和权限验收方案；尚未创建/执行 0008+ 迁移。
- 固定 Action 提交版本的 CI：单元测试、Web 构建及数据库设计/SQL 离线检查。

## 下载与使用

| 文件 | 用途 |
| --- | --- |
| `Reso-v0.1.0-android-arm64-debug.apk` | Android 7.0+、ARM64、包名 app.reso.local，连接现有 https://openwook.cloud；调试签名，不是商店发布包 |
| `Reso-v0.1.0-web-dist.tar.gz` | 当前 tag 对应的 Web 前端构建；需与 API/Worker/PostgreSQL 配合部署，不包含后端服务或数据库 |
| `SHA256SUMS` | 下载文件的 SHA-256 校验值 |
| `RELEASE-MANIFEST.json` | 发布源码提交、产物与验证范围 |
| GitHub Source code | 当前 tag 的完整公开源码；启动/配置见 README |

Android 安装包加载现有服务器页面。本次发布没有更新服务器代码或数据库，线上页面不保证与 tag 的 Web 源码同步。安装前也应知悉：调试包可能与既有相同包名应用冲突，需要兼容签名；本次不自动卸载或修改设备数据。

## 当前验证

- 109 项单元/组件测试通过；TypeScript 检查及 Vite 构建通过。
- 294 项 JSON 例、398 项关系/状态例，共 692 项设计检查通过。
- 五份 SQL 草案离线自检通过：47 个合法阶段分支，243 个破坏版本被拒绝；7 个既有迁移文件摘要和清单未变。
- Android ARM64 服务器调试包构建、包名/版本/ABI 检查及 APK v2 签名验证通过。
- 现有公开服务器状态接口返回 HTTP 200；此检查不代替模型、语音或端到端业务验收。

本次没有重跑数据库集成、真实模型/语音、真机或 AVD 验收，也未验证目标表的实际 RLS、并发事务、回填或专业有效性。运行库仍以 0001–0007 为基线；目标草案不应连续执行或当作已上线。

## 公开范围

公开端仅推送已去除个人设备路径/微信标识的源码快照；原本地历史保留在本机，没有重写或强推。`.env`、聊天/附件原件、数据库、备份、签名私钥和本地证据没有随仓库/Release 发布。参考资料和 UI 素材说明见 `docs/source-materials.md` 及 `public/assets/README.md`；本次没有新增第三方素材许可声明。
