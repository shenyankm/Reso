# Reso 移动端 UI 验收

日期：2026-11-13。

## 打开方式

- 本机：http://localhost:5173/
- 同一 Wi-Fi 下的手机：http://192.168.124.115:5173/
- 右上角「…」切换场景；聊天输入框「＋」打开工具。
- 重启服务：项目根目录执行 `npm run dev -- --port 5173 --strictPort`。

## 本轮范围

复刻欢迎、私聊、问卷题卡、小发现、练习推荐、五幕叙事、事件记忆、邀请、三方会谈、双视角、音乐卡片、咨询师推荐、咨询申请、安全支持与我的关系，共 15 个可切换场景。复用原稿角色与插画，按钮、文字、表单和导航为 React 组件。

五幕按 PRD 补齐第四幕与第五幕；第四幕复用现有插画。另两种练习暂为说明卡片，不含完整练习。视频及专家工作台不在本轮范围。
