# 主界面简化验收

2026-11-14，沿用 Reso UI V2.1 的角色、配色和聊天卡片。本轮改动仅涉及共享前端与本记录，没有修改后端、原生容器或数据库结构。

## 简化内容与入口

- 私聊与公开房间隐藏底部主导航，保留顶部返回及系统返回；回到其他页面后显示主导航。输入区保留底部安全区，聊天提示浮层随输入区上移。
- 聊天正文移除重复的问卷、练习和整理按钮；相应功能集中在输入框的“＋”聊天工具中。已开始但未保存的叙事练习显示继续入口。
- 工具以文字列表替换大色块宫格，保留三组渐进展开；房间只有一组，直接显示房间专用动作。
- 事件名称、改名和菜单合并为一处事件入口；改名移入事件菜单，分享、申请、删除与退出仍保留原有入口和确认。入口的无障碍名称包括事件名与可见范围。
- 关系列表改为平铺行，权限与日期合并显示，新建与回访集中在列表上方。没有事件时直接开始聊天，之后可在事件菜单改名；重要人物空状态返回已有对话，避免为了离开空状态而创建另一件事。
- 搜索按当前标签提示目标；无匹配时显示清除搜索，避免与尚无记录的空状态混淆。

未删除业务功能。聊天工具的发现率，以及取消正文快捷按钮后练习的进入频率，仍需后续用户反馈验证。

- 16 条针对实际 UI XML 的断言通过，包括私聊/房间隐藏导航、关系页保留导航、工具功能保留与无障碍事件名称。脚本与结果位于 `.data/distill/verify.py`、`acceptance.json`。
- 检查正常 412 CSS px 宽与 320 CSS px 窄屏、系统字体 130%、系统夜间模式切换。保持原有浅色界面，未新增暗色主题。设备分辨率、字体与夜间设置已恢复。
