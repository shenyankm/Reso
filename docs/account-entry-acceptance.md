## 移除或合并

| 原入口 | 调整 |
| --- | --- |
| “聊过的事”及其他有底部导航页面的右上角账户菜单 | 移除，通过底部“我的”访问账户功能 |
| 聊天页中央“我的空间”弹窗 | 改为右上角人形图标旁的轻量非模态菜单，仅含“我的”和“安全与人工支持” |

| 空聊天页“打开聊天工具”按钮 | 改为说明文字，只保留输入栏左下角加号作为工具入口 |
| “聊天工具”里的“这件事的记录” | 移除，统一从事件操作菜单进入 |

## 保留的不同用途

- “我的记录”用于跨事件查找已保存内容，事件内记录用于查看和继续处理单件事。
- 邀请页的摘要编辑、记录页的“邀请一起聊”是当前任务的直接下一步；事件操作菜单提供集中管理。
- 安全支持在“我的”、聊天快捷菜单和相关沟通流程中保持可达。
- “Reso”固定进入私人聊天；事件菜单中的房间切换用于明确切换消息可见范围。

聊天快捷菜单支持点空白、Esc 与 Android 系统返回关闭；打开和关闭不改变消息草稿。使用浏览器原生 Popover 处理轻量显示和焦点行为，位置按触发按钮的实际边界计算，不依赖当前 AVD WebView 尚未支持的 CSS Anchor Positioning。屏幕尺寸变化时重新定位。
