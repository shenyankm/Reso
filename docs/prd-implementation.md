## 本轮验证

`npm test`：10 项单元及组件静态渲染测试；`npm run test:integration`：6 项真实 PostgreSQL 隔离场景；`npm run build`：类型检查和生产构建。集成场景使用受限运行角色和注入模型，不调用真实供应商。

本机已执行 0004，升级前备份恢复比对的 19 张原表保留字段一致，配置文件未变；Web、API、Worker 实际启动、代理状态与未登录拒绝均通过，检查进程已停止。新增 UI 的静态渲染检查不代表真实浏览器验收：本轮浏览器工具报告 `native pipe closed before response`，未完成点击、移动端布局和录音验收。历史浏览器截图不覆盖本轮新增界面。

Tauri Android 本机调试包已交付并完成基础 AVD 验收，详见 [Android 说明](android.md)；生产 App 发布、附件存储、音乐、完整专业方法库、生产邮件验证／找回和正式安全运营仍未交付。原 PRD 中的视频明确为探索范围。供应商与真实专业服务联调、专业审核和使用效果验证仍是后续验收条件。

同日执行工程审查与优化，当前累计 16 项单元／渲染测试、15 项数据库集成场景通过，本机迁移为 0005。此节更新工程验证基线，不改变上表的业务和专业验收限制；原 0004 阶段的浏览器故障记录不代表本轮已完成浏览器验收。修复、数据保护和合成 SQL 测量见 [engineering-stability.md](engineering-stability.md)。

## 功能链路 E2E 复核（2026-11-14）

新增可重复的 Android 页面→HTTP→隔离 PostgreSQL→持久队列→Worker 多角色验收，以及原生文件保存专项。当前单元／组件 28 项、数据库集成 18 项通过，详细链路、最终运行证据、修复和真实供应商结果见 [功能验收](e2e-acceptance.md)。这次真实 DeepSeek 回复成功；豆包转写仍被资源授权阻断，不将供应商替身通过算作真实语音畅通。上文旧日期的测试数量与浏览器故障保留为历史记录。

## Agent 执行深化（2026-11-14）

已实现按需工具循环与恢复、历史原话查证、练习和理解修正读取、真实核验目录查询；私人摘要、表达练习和回访可由 Agent 生成可编辑建议，再由本人确认写入。建议保留原话来源，旧上下文失效，确认幂等，不会自动分享或预约。问卷正式计分仍由代码负责，五幕页面仍沿用现有流程。本轮工程和真实合成行为验收见 [Agent 设计](agent-design.md)，不将这次改造宣称为完整专业方法库或临床效果验证。
