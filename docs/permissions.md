# 权限矩阵与验证

2026-11-13。单体 API、独立 Worker；会话由 Better Auth 管理，数据归属与业务授权由服务端检查。本轮没有新增通用角色管理或权限配置框架。

## 权限来源

- 事件所有者：events.owner_id。
- 房间成员：members 中 event_id、user_id 匹配且 active=true；事件所有者也可参与公开房间。
- 分享：share_grants 未撤回且接收人仍是有效成员，关联同一事件的固定 share_snapshots。
- 咨询人员：consultants.user_id 匹配且 active=true。profiles.role 保留为旧业务元数据，不授予专业端权限；GET /api/me 从有效咨询人员记录派生展示角色。
- 会话：有效 session 及未过期的 expiresAt。SSE 保存当前 session ID，推送及心跳均查数据库重新验证。
- 开发测试说明：不再作为登录、业务写入或 Worker 调用的前置条件；历史同意记录保留，登录不代替用户写入 accepted。摘要、邀请与纪要分享仍由现有授权规则控制。

## 统一检查

server/permissions.ts 提供 requireEventOwner、requireRoomParticipant、hasEventAccess、requireActiveCounselor、hasSession。路由、Worker 初始上下文、回复发布前检查和 SSE 使用同一组事件访问规则。

咨询人员改变申请状态时，在事务内锁定申请并对有效咨询人员记录执行 FOR SHARE，停用更新与状态变更串行。读取工作台的最终查询也包含 active 条件。申请人取消与拒绝时间提议独立判断，不会因咨询人员停用而被锁住；接受提议则重新检查咨询人员是否有效。

事件消息和观点写入在事件行锁内再次检查参与资格；分享、退出、撤回与上下文版本在同一事务内变化。模型执行结束后核对当前权限与版本，过期结果不发布。

## SSE 与活动隐私

通知必须包含 eventId 和 private／room 范围；订阅端拒绝格式错误或旧版无范围的通知。私人聊天、问卷、练习、事件摘要和咨询申请只通知事件所有者；公开消息、分享范围和成员变化只通知仍有房间访问权的用户。

每次推送前检查当前 session 及有效成员资格。注销、服务端撤销会话、到期后，下一次推送直接结束连接；没有业务事件时，最多在下一次 15 秒心跳检查结束。成员被移出后，旧连接不再收到该事件的更新，也不能重新读取或发送房间消息；其其他有权事件仍可使用同一连接。

events.room_updated_at 独立记录公开活动。房间成员查询事件列表及详情时，updated_at 使用公开活动时间，避免通过轮询观察所有者私聊更新时间。私人信息变化不递增公开上下文版本。

## 数据库角色

MIGRATION_DATABASE_URL 用于认证表、业务迁移、队列初始化、运行角色配置和本地测试咨询人员开通。现有 Docker 管理账号保留为运维／迁移凭据，不再用于 API 或 Worker。

DATABASE_URL 是专用运行账号：禁止超级用户、建库、建角色、继承其他角色、绕过 RLS、建 Schema、建表、临时表、表结构修改和对象所有权。启动时再次校验，拒绝管理员账号或过期迁移。

| 对象 | 运行权限 |
| --- | --- |
| user、session、account、verification、events | SELECT、INSERT、UPDATE、DELETE |
| messages、questionnaires、exercises、members、invites、share_grants、perspectives、applications、agent_runs、understandings、understanding_confirmations、followups、consultation_notes、note_shares | SELECT、INSERT、UPDATE |
| profiles、consent_records、share_snapshots、revisions | SELECT、INSERT |
| consultants | SELECT；额外 UPDATE(name) 用于 PostgreSQL FOR SHARE 所需的列权限，不能修改 active、user_id 或新增专业身份 |
| schema_migrations | SELECT |
| 公共业务及队列序列 | USAGE、SELECT |
| pg-boss 表 | SELECT、INSERT、UPDATE、DELETE，支持任务消费、重试、监督与清理 |
| pg-boss 函数 | 仅授予 job_now()；创建队列等 DDL 函数限迁移账号 |

运行时不创建队列、不自动迁移 pg-boss、不创建持久统计分区或重建索引，监督与失败重试保持启用。依赖升级或新增表后重新运行迁移命令，以更新结构与明确授权。

开发启动器不会把 MIGRATION_DATABASE_URL、POSTGRES_PASSWORD 放入 API/Worker 进程环境。开发 `.env` 仍位于本机文件系统；正式运行容器只应持有运行配置，管理员配置留在运维或发布环境。

## 本轮验证

7 项单元测试、4 项 PostgreSQL 集成场景以及构建通过。新增场景验证：停用咨询人员不能读取或改变申请状态、申请人仍可取消、伪造展示角色无效、私聊通知及时间隔离、房间公开更新正常、移出后旧连接不再获通知、注销及会话到期关闭连接。

受限账号实际完成注册、同意、事件和消息写入、pg-boss 入队与取出、Agent 注入模型回复、任务完成、失败重试与监督；越权 DDL、修改专业身份及迁移记录均被数据库拒绝。未调用真实模型或语音供应商。

本地数据库已迁移至 0003，保留的 19 张认证及业务表逐表与升级前备份恢复的临时库比对，数据一致；供应商密钥与会话密钥保留。实际 Web、API、Worker 启动和匿名访问拒绝检查通过，进程环境不含管理连接和管理员密码。脱敏记录见 .data/permissions-fix/，私有备份见 .data/backups/。

未进行生产部署、外部渗透测试或高并发安全评估；上述验证不代表所有潜在越权路径已被穷尽。

## PRD 流程补齐后的验证（2026-11-13）

当前累计 10 项单元及组件静态渲染测试、6 项 PostgreSQL 集成场景及构建通过。补充验证：练习／回访不进入公共 Agent；原消息不可跨会话引用；修改理解后旧确认失效；单方、共识与分歧分别计算；预约需要申请人确认当前提议；停用人员不能获得新的预约确认，用户仍可拒绝；纪要草稿不进入申请人详情、导出或任何 Agent；固定版本分享、撤回及退出重入不复活授权。

仅受邀者本人可在房间详情读取单独分享的纪要，其他成员无权读取，公共 Agent 也不读取。纪要变化仅通知事件所有者，接收人通过现有定期刷新／回到页面更新，不向整个房间广播私人纪要活动。

该阶段本地迁移版本为 0004。升级与原数据比对、匿名接口 401、Web/API/Worker 实际启动均通过；该次检查禁用了模型调用，进程已停止。新增界面尚未做真实浏览器点击验收，工具报告 `native pipe closed before response`。

## 工程稳定性复核（2026-11-13）

当前本地迁移为 0005，权限矩阵与数据库运行角色授权保持不变。SSE 突发合并仍在每轮推送前检查会话与资源访问，不向未授权用户推送事件；慢读连接结束后可按原权限重连。通知订阅中断时自动重建，通知故障不影响已提交数据。

成功、失败回复发布均核对当前事件版本及资格；丢失会话锁或停机时取消模型并阻止发布。前端会话失效后取消旧读取并清理私人状态。HTTPS PUBLIC_ORIGIN 启用 Secure Cookie，受信来源忽略两侧空格。

当前 16 项单元／渲染测试、15 项 PostgreSQL 集成场景及构建通过，包含连接拒绝、真实后台连接终止与恢复。未做真实浏览器、外部供应商压测或生产渗透验收。详见 [工程稳定性报告](engineering-stability.md)。
