# 私人聊天、练习与邀请流程修复

2026-11-15。对应 `.impeccable/critique/2026-11-15T01-18-13Z__src-mvpapp-tsx.md` 的四项优先问题，沿用 UI V2.1 的角色、色彩、卡片、按钮与弹窗样式。

## 行为变化

- 聊天工具使用固定加号，发送使用独立按钮。输入草稿后仍可进入练习，返回聊天保留原草稿；空消息不能发送。
- 接受邀请前显示邀请人的账号昵称、当前成员昵称以及房间历史的可见范围。信息读取失败时不能接受，保留拒绝和重试。
- 邀请页可直接打开现有事件摘要编辑器；私人故事不自动填入分享摘要，摘要保存后不会自动勾选分享，也可以不附摘要邀请。
- 成员聊天的标题和进入按钮统一使用“房间聊天”。
- 窄屏下长邀请卡片不再被 flex 布局压缩，由外层页面滚动到完整内容和操作；摘要弹窗标题与关闭控件随内容滚动保持可见。

## 接口与隐私

匿名 `GET /api/invites/:token` 保持基础元数据。新增 `GET /api/invites/:token/details` 由现有登录中间件保护；有效待接受邀请仅返回事件房间标题、是否附带摘要、发起人昵称和当前有效成员昵称，不返回邮箱、成员 ID、私聊、私人故事或摘要正文。昵称不是身份认证。过期、取消或已接受邀请不能继续读取详情。

前后端已于 2026-11-15 一起部署到 https://openwook.cloud，版本为 `20261115T040956Z-ui-fixes`；无数据库迁移或新增依赖。发布和直连线上 AVD 验证见 [服务器部署](deployment.md#ui-流程修复同步发布2026-11-15)。
