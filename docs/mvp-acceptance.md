# 第一版本地 MVP 验收记录

日期：2026-11-13。需求依据 `prd.md` 与 `tech-stack.md`；保留 Reso UI V2.1 的视觉与移动端布局。

## 已完成与验证

| 范围 | 结果与证据 |
| --- | --- |
| 账号与持久化 | 浏览器创建独立测试账号，发送私人消息、保存摘要；刷新及 API 重启后恢复。PostgreSQL 保存正式记录。 |
| 问卷 | 浏览器选择答案，刷新重新打开后选项保留；单元测试验证 24 题索引、输入校验和八个独立均分。 |
| 五幕练习 | 浏览器进入第一幕并暂停，刷新后恢复幕次和暂停状态；每幕修改与故事由数据库保存，插图不视为用户事实。 |
| 邀请与分享 | 浏览器生成测试邀请并取消；集成测试验证接受、拒绝、单次加入、快照固定、私聊隔离与访问撤回。 |
| 多人上下文 | 集成测试验证私人改名和新摘要不泄露；只有部分成员获授权的摘要不进入公开 Agent 上下文；事件发起者与成员观点均可进入公共上下文。 |
| 异步回复 | 本地真实 Worker 消费消息；缺少 DeepSeek 密钥时保存明确错误，提供重试。测试验证上下文版本变化时不发布过期回复。 |
| 专业支持 | 隔离数据库测试四个账号，验证申请、接单、约定时间、取消及摘要访问边界；真实目录默认空。 |
| 响应式 | 浏览器检查 320、390、429、1440 像素宽；聊天未出现横向溢出。截图存于 `.impeccable/review/mvp-*.jpg`。 |
| 分享界面状态 | 切换事件和退出账号时清空旧邀请链接、分享勾选及咨询选择，避免把前一事件的授权带入新事件。 |

自动检查：`npm test` 的 6 项测试、`npm run test:integration` 的多账号真实 PostgreSQL 集成测试、`npm run build` 均通过。集成测试使用单独随机数据库，结束后只删除该隔离数据库。

界面独立复核的最终局部结论为 **ship**：旧邀请链接与分享选择跨事件残留的问题已修复；此结论仅覆盖该问题，不代表供应商或完整 PRD 已验收。

浏览器验收资料属于独立的“本地验收测试”账号，未写入用户账号；验收结束已退出。

## 尚未验收

后续真实联调结果见 [provider-check.md](provider-check.md)：DeepSeek 已通过应用完整链路；豆包仍在上游鉴权阶段返回 401，尚未验证转写准确率与延迟。模型支持效果仍需另行评测。手机真实设备、移动端 HTTPS 和录音权限兼容性尚未验证。模拟模型只注入自动测试，运行时无模拟回复开关。

本版未实现完整专业方法库、音乐服务、附件存储或生产邮件流程；Tauri Android 本机调试包的后续验收见文末。原 UI 演示中的示例音乐与老师卡片仍只属于 `/?preview=1`。安全支持不代表实时人工值守；量表效度、未成年人合规和真实专业服务需另行验收。

## 数据库与后端重构复核（2026-11-13）

7 项单元测试、2 项 PostgreSQL 集成场景及类型检查和构建通过。新增覆盖旧数据升级、失败回滚、并发迁移与校验和拒绝；分享和房间资格独立撤回、重新授权、授权变更时丢弃模型结果、同意版本重新确认以及 Agent 消息关联和错误记录。

本地实际数据库已升级，并从升级前备份恢复临时库进行保留字段及内容比对；用户、事件、消息、练习、问卷和邀请等数据一致。备份和脱敏验证数量存放在 .data/。新增“撤回摘要／分享当前摘要”与版本同意界面尚未做浏览器实测：本轮浏览器工具报告 native pipe 启动失败，前述历史截图和局部 ship 结论不能作为这次新增界面的验收。详细范围见 [database.md](database.md)。

## 权限修复复核（2026-11-13）

7 项单元测试、4 项 PostgreSQL 集成场景、类型检查和构建通过。新增场景使用受限数据库账号验证 HTTP、真实 SSE 长连接、入队及 Worker 回复处理；咨询人员停用、成员移出、注销、会话过期和私聊活动隔离均有回归断言。运行账号被验证无法建表、建 Schema、建临时表、建角色、修改专业身份或迁移记录，任务监督和重试仍正常。

本地配置已分离运行与迁移连接，19 张认证和业务表的数据与备份一致，原模型、语音和会话密钥未变。实际启动检查确认 API/Worker 使用受限账号且进程环境无管理连接或管理员密码；检查结束已停止临时启动的 Web、API、Worker。范围与限制见 [permissions.md](permissions.md)。

## PRD 流程补齐复核（2026-11-13）

当前累计 10 项单元及组件静态渲染测试、6 项 PostgreSQL 集成场景、类型检查及生产构建通过。新增验证覆盖：

- 保存的五幕练习、故事、非暴力沟通与排练笔记、回访进入私人上下文，公共上下文不读取；更新后丢弃旧回复。
- 理解来源消息与原说话人保留；跨会话引用被拒；单方确认、全体确认和分歧独立呈现，修正后旧确认失效。
- 显式危险消息产生聊天内 safety 卡并暂停练习；尚无练习记录时也保存暂停状态。
- 旧单方排期迁移为待确认提议，完成历史保留；新提议仅申请人可确认，旧版本和停用人员不能获得新确认，拒绝和取消仍可操作。
- 纪要草稿隔离、非分配人员不能编辑、固定版本单独分享、独立撤回、隐藏当前纪要后旧分享仍可撤回、退出再加入不复活旧授权。
- 事件导出包含房间、理解与确认、回访、申请和开放纪要，不泄露专家草稿；删除级联清理新记录。
- 组件静态渲染验证待确认预约和可撤回旧纪要的入口，以及存在分歧时不会显示共同确认；URL 解析拒绝错误域与无效 ID。

本机已升级至 0004，19 张原表保留字段与本轮升级前备份一致，五张新增表初始为空，配置逐字节未变。实际 Web、API、Worker 启动与匿名接口拒绝检查通过；临时禁用模型 Key，未调用供应商，检查进程已停止。数据及启动脱敏记录在 `.data/prd-completion/`，私有备份在 `.data/backups/`。

新增界面没有真实浏览器点击验收，本轮工具仍报告 `native pipe closed before response`。真实咨询目录、排班运营、语音鉴权、专业安全审核与模型效果不能用本轮自动测试替代，完整对照见 [prd-implementation.md](prd-implementation.md)。
