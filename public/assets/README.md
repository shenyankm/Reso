# Reso UI 素材来源

本目录 WebP 图片提取自用户提供的 `Reso_UI_V2.1_编号图片_21张.zip` 中的原图备份，用于本次移动端 UI 复刻。

- `reso-welcome`：UI-01 的 Reso 招手形象。
- `reso-avatar`、`reso-hug`：UI-02 的角色头像与抱抱贴图。
- `reso-empty`：UI-20 的空状态角色。
- `story-1`、`story-2`、`story-3`、`story-5`：UI-07、08、09、10 的插画区域。第四幕复用第一幕插画，按 PRD 补齐五幕。
- `teacher-lin`、`teacher-zhou`、`teacher-zhang`：UI-16 的示例头像，仅作界面展示，不代表真实服务或资质。

未将整页截图作为页面实现。页面文字、按钮、卡片、表单与导航由 React 渲染。
